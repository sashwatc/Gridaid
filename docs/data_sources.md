## Quality and artifacts

Current graph: 19,205 nodes / 51,911 directed edges; 37 weak / 80 strong components. Disconnected components are retained, not silently removed to improve coverage. Geometry validity, finite bounded coordinates/speeds, duplicate identifiers, missing required values and snapping are validated. The directional parser is independently tested for reverse one-way, mph conversion, private access and contraction length preservation. Road speed assumptions are explicit; 32,475 simplified edges use class defaults.

`data/public/iowa.json.gz` is a committed compressed snapshot for a download-free demo. Its embedded manifest contains raw URLs, request parameters, UTC retrieval times, hashes, CRS and assumptions. Read `data/public/LICENSE.md`. `data/processed` contains local regenerated JSON, GeoParquet, matrices and known offline model artifacts; `data/raw` contains ignored hash-checked raw snapshots. API responses carry content-derived dataset/model versions and scenario/matrix identity. See README for ordered rebuild commands.

## Exact blocked sources / alternatives

- ACS 2023 API redirected HTTP 302 to `https://api.census.gov/data/missing_key.html`; no key was supplied. Official 2020 population was retrieved successfully and is dated explicitly.
- `overpass-api.de` returned HTTP 406 to both GET and POST. Kumi/private.coffee mirrors timed out at 20 seconds. Dated Geofabrik extraction succeeded.
- [Iowa DOT 511 XML feeds](https://iowadot.gov/travel-tools/iowa-511/511-data-feeds) require an access request. No credential/access request or contact was made. Live feed and cached historical Iowa 511 replay are unavailable. The normalized feed adapter is tested with strict schemas/failures/cached fallback; it is not represented as an implemented XML integration.
- Historical as-of crash-report timestamps and historical road/AADT vintages were not supplied. Current traffic fields are excluded from training; lag counts are retrospective. Operational freshness and reporting-delay claims remain unverified.

## Continuation geographic audit

Official Census2020 TIGERweb incorporated-place layer 26 was queried for the expanded selected-tract neighborhood; URL/parameters/retrieval/hash are in geography_audit.json. This enables dated place classification and selected-tract/place intersections, not city population apportionment. All 39 original internal points and all 32 assumed candidates are enumerated. See geography.md for rectangle, whole-tract union and irregular graph bounds. The public snapshot now preserves original and projected coordinates and directed segment approaches; default times include an explicit assumed access leg. Max gap remains 871.046 m, median falls from 59.095 m at junctions to 36.440 m at road projections. ML forecasts and model artifacts are unchanged.
