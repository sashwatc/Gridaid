# Threat model and executed controls

Assets: result and dataset/model integrity, local API availability, source provenance/freshness, secrets and user trust. Inputs are unauthenticated planning parameters and untrusted public-data snapshots. There are no accounts, private responder data, patient records or precise user-location inputs.

| Threat / boundary | Executing control | Local evidence / limits |
|---|---|---|
| Expensive-request exhaustion | 30 expensive requests/minute/client, max 2 active worker processes; candidate/demand/graph/request/trial caps; solver 1–5000 ms; independent 20-second process deadline with terminate/kill/join | Rate/capacity/deadline tests execute. Bounds apply to model construction/routing too through the process deadline. Single Uvicorn process; multi-replica coordination is not implemented. |
| Malformed inputs / NaN / unknown IDs | Strict Pydantic bodies, forbidden extra fields, finite bounds, enums, unique bounded scenario/run lists; validate resources against dataset; safe 422 responses without input echo | API malformed/oversized/nonfinite/unknown tests. Middleware reads at most 16 KiB even without reliable Content-Length. No arbitrary upload/data URL/model paths. |
| Stale or mixed results | Run ID, complete controls, exact scenario snapshots, dataset/model versions, matrix keys; max 100 isolated runs; simulation rejects changed inputs; UI marks stale results and ignores old request responses | API isolation, cache mutation/corruption, scenario-change regression, and browser stale-control tests. Runs are ephemeral, not an authenticated private store. |
| Cache/data tampering | Content-hashed matrices and shape/value checks; raw acquisition hashes; schema-validated snapshots; artifact hash/version; known offline model only | Cache corruption test; reproducible builds. Local filesystem and supplied repository are trusted; there is no signed supply-chain system or sandbox for hostile local files. |
| Malformed external source / SSRF | No fetch route; fixed HTTPS host allowlist, no redirect following, explicit read/connect timeouts and size bounds; paginated row caps, geometry/schema audits; UTC source timestamps and cached raw replay | Mocked host/redirect/size/failure/stale-cache tests; real Census/OSM/DOT retrievals. Normalized feed adapter validates event fields; actual Iowa 511 XML integration remains blocked by access. |
| XSS / browser misuse | React escaped content; no unsafe HTML; self-only script CSP, restricted image/connect policy, frame/object/base restrictions; nosniff, frame DENY, no-referrer, geolocation/camera/mic denied | API header tests and actual Chromium workflow. Leaflet needs inline styles; style-src allows them. Optional OSM tile images are separately allowed and off by default. |
| Cross-origin requests | Local-origin allowlist, GET/POST only, Content-Type header only; forwarding headers not used for rate identity | Allowed/disallowed origin tests. Deployment proxy origin configuration is separate. |
| Stack traces / debug | debug=false, generic production computation errors, safe request errors | Deliberate exception test contains no sensitive exception text and retains security headers. |
| Dependency / credential compromise | Frozen Python/npm locks, pip-audit/npm audit/Bandit/detect-secrets; .env ignored, no frontend secrets | Scan records in validation.md. Entropy findings reviewed as public hashes. No arbitrary pickle/joblib loading in runtime. |
| HTTPS / transport interception | Requires a properly configured TLS reverse proxy and HSTS on a real HTTPS host | **Not locally verified or deployed.** Local HTTP does not meet this release gate. Do not enable HSTS as a claim of tested TLS. |
| Forecast leakage / overstated results | Train-only preprocessing, temporal/geographic holdout, baseline comparisons, honest solver labels and unreachable metrics, model period/provenance in UI | Structural tests and held-out report. Historical as-of reporting latency is unavailable; prospective reliability is unverified. |

The local process limit bounds computation, not network slow-client behavior at internet scale. A public deployment would require transport timeouts, coordinated limits, appropriate proxy trust, operational logging review, TLS and independent security testing. Those are deployment-dependent requirements, not claims established by this local demo.

## Continuation corrections verified by independent counterexamples

The previous poll-based deadline did not bound receiving a partly emitted IPC result. Receiving now runs under the same deadline; stalled workers are terminated/joined. Request cancellation previously released a still-running worker's slot; shielded tracked jobs now retain capacity until physical work completes. Both counterexamples failed before the changes and pass afterward. Derived-cache eviction during reads is now recoverable, and verified bytes are loaded directly rather than reopening a potentially replaced file. A real browser response-delay test also confirmed/fixed old simulation results reviving after the trial count changes. These are local executing controls, not distributed or deployed load-testing claims.
